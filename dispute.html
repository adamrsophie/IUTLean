The dispute

In 2018 Peter Scholze and Jakob Stix raised objections, in the manuscript Why abc is still a conjecture, to the proof of IUT III, Corollary 3.12. Shinichi Mochizuki responded in a report and in comments on their manuscript. This page sets the two positions side by side and maps them to precise propositions.

Neutral presentation. Neither party's reputation counts as evidence. A Lean theorem on this page checks an elementary step of one argument under stated hypotheses; none of them settles the dispute, and the hypotheses on which the two sides disagree are named in each docstring.

The objections

This document lists, item by item, what P. Scholze and J. Stix assert in Why abc is still a conjecture, states each assertion as a precise proposition where one can be stated, names the hypotheses it rests on, and points to the corresponding passage of the four IUT papers. Mochizuki's responses are in docs/MOCHIZUKI_RESPONSES.md; the mapping between the two is in data/dispute_map.json and in the table at the end.

What is checked in Lean

The arithmetic of the objections

IUT.Audit.ScholzeStix.Blurring

Scholze–Stix, end of Section 2.2: the size of the "blurring"

IUT.Audit.ScholzeStix.consistentUpTo_one_iff

ConsistentUpTo 1 is the same as Consistent.

Lean statement
theorem consistentUpTo_one_iff (cycle : List LinIdent) :
  ConsistentUpTo 1 cycle ↔ Consistent cycle

IUT.Audit.ScholzeStix.blur_bound

One edge with scalar s, all others canonical: the cycle closes up to the factor B exactly when 1/B ≤ s ≤ B.

Lean statement
theorem blur_bound (s : LinIdent) (n : ℕ) (B : ℝ) :
  ConsistentUpTo B (s :: List.replicate n LinIdent.canonical) ↔ 1 / B ≤ s.scalar ∧ s.scalar ≤ B

IUT.Audit.ScholzeStix.avgSq_eq

With ℓ = 2ℓ* + 1, the average of j² is ℓ(ℓ + 1)/12.

Lean statement
theorem avgSq_eq {lh : ℕ} (hlh : 1 ≤ lh) {l : ℝ} (hl : l = 2 * lh + 1) :
  avgSq lh = l * (l + 1) / 12

IUT.Audit.ScholzeStix.consistentUpTo_avgSq_iff

Under (Lin) and the tolerance model ConsistentUpTo: a cycle whose one edge carries the averaged scalar avgSq ℓ* and whose other edges are canonical closes up to the factor B exactly when 1/B ≤ ℓ(ℓ + 1)/12 ≤ B. This is an evaluation of the hypothesis ConsistentUpTo B, not a derivation of a lower bound on B from other premises.

Lean statement
theorem consistentUpTo_avgSq_iff {lh : ℕ} (hlh : 1 ≤ lh) {l : ℝ} (hl : l = 2 * lh + 1) (n : ℕ)
  (B : ℝ) (hpos : 0 < avgSq lh) :
  ConsistentUpTo B (⟨avgSq lh, hpos⟩ :: List.replicate n LinIdent.canonical) ↔
    1 / B ≤ l * (l + 1) / 12 ∧ l * (l + 1) / 12 ≤ B

IUT.Audit.ScholzeStix.withSquares_eq_withoutSquares_scaled

The j-th summand form of (1.5) and (1.6) differ only in the q term, and after averaging the q term of (1.5) is the q term of (1.6) multiplied by avgSq ℓ*: thetaWithSquares = (ℓ* + 1)/2 · d − avgSq ℓ* · qE/(2ℓ) and thetaWithoutSquares = (ℓ* + 1)/2 · d − qE/(2ℓ).

Lean statement
theorem withSquares_eq_withoutSquares_scaled {lh : ℕ} (hlh : 1 ≤ lh) (l d qE : ℝ) :
  thetaWithSquares lh l d qE = ((lh : ℝ) + 1) / 2 * d - avgSq lh * (qE / (2 * l)) ∧
    thetaWithoutSquares lh l d qE = ((lh : ℝ) + 1) / 2 * d - 1 * (qE / (2 * l))

IUT.Audit.ScholzeStix.Diagram

Scholze–Stix, Section 2.2: consistency of identifications of copies of ℝ

IUT.Audit.ScholzeStix.consistent_canonical

The cycle with canonical identifications on every edge is consistent. Scholze and Stix: "There is one consistent choice of isomorphisms given by using the natural isomorphisms".

Lean statement
theorem consistent_canonical (n : ℕ) : Consistent (List.replicate n LinIdent.canonical)

IUT.Audit.ScholzeStix.scalar_eq_one_of_consistent

If one edge carries the scalar c and all other edges are canonical, the cycle is consistent only if c = 1.

Lean statement
theorem scalar_eq_one_of_consistent (c : LinIdent) (n : ℕ)
  (h : Consistent (c :: List.replicate n LinIdent.canonical)) : c.scalar = 1

IUT.Audit.ScholzeStix.not_consistent_square

The case at issue: the scalar j² for j ≥ 2. Under (Lin), with the other edges canonical, the cycle has "monodromy j²" and is inconsistent.

Lean statement
theorem not_consistent_square {j : ℕ} (hj : 2 ≤ j) (n : ℕ) :
  ¬ Consistent (⟨(j : ℝ) ^ 2, by positivity⟩ :: List.replicate n LinIdent.canonical)

IUT.Audit.ScholzeStix.Reduction

Scholze–Stix, Section 1.2: from Claim 6 to Vojta's inequality, as real analysis

IUT.Audit.ScholzeStix.display_after_claim6

The display after Claim 6 (page 3), for one point, assuming β ≥ 0: h · (1 − (c (1 + h^{−1/2}) + β (c₁ + c₂ log h)) / h^{1/2}) ≤ (1 + α) N. Hypotheses: h12 is (1.2) in the form Scholze and Stix use, hC6 is Claim 6, h13 is the upper half of (1.3).

Lean statement
theorem display_after_claim6 {h Q N ℓ α β c c₁ c₂ : ℝ} (hh : 0 < h) (hβ : 0 ≤ β)
  (h12 : h ≤ Q + c * (√h + 1)) (hC6 : Q ≤ (1 + α) * N + β * ℓ)
  (h13 : ℓ ≤ √h * (c₁ + c₂ * Real.log h)) :
  h * (1 - (c * (1 + (√h)⁻¹) + β * (c₁ + c₂ * Real.log h)) / √h) ≤ (1 + α) * N

IUT.Audit.ScholzeStix.display_after_claim6_abs

The same display with |β| in place of β, for arbitrary real β. Claim 6 with β implies Claim 6 with |β| because ℓ ≥ 0.

Lean statement
theorem display_after_claim6_abs {h Q N ℓ α β c c₁ c₂ : ℝ} (hh : 0 < h) (hℓ : 0 ≤ ℓ)
  (h12 : h ≤ Q + c * (√h + 1)) (hC6 : Q ≤ (1 + α) * N + β * ℓ)
  (h13 : ℓ ≤ √h * (c₁ + c₂ * Real.log h)) :
  h * (1 - (c * (1 + (√h)⁻¹) + |β| * (c₁ + c₂ * Real.log h)) / √h) ≤ (1 + α) * N

IUT.Audit.ScholzeStix.vojta_pointwise

The step "we conclude Vojta's inequality" (page 3), for one point: if h · M ≤ (1 + α) N and 0 < 1 + α < M (1 + ε) with ε > 0, and N ≥ 0, then h ≤ (1 + ε) N. Here M stands for the factor 1 − (…)/h^{1/2} of the previous display.

Lean statement
theorem vojta_pointwise {h N α ε M : ℝ} (hε : 0 < ε) (hN : 0 ≤ N)
  (hdisp : h * M ≤ (1 + α) * N) (hα : 0 < 1 + α) (hlt : 1 + α < M * (1 + ε)) :
  h ≤ (1 + ε) * N

IUT.Audit.ScholzeStix.vojta_of_claim6

The reduction of Section 1.2. Scholze and Stix: "the inequalities of Claim 6 and (1.3) yield [the display]. … As soon as for large h(P) … we conclude Vojta's inequality h(P) ≤ (1 + ε)(d(P) + n¹_∞(P)) + O_{ε,d}(1)." Hypotheses, uniform over the index type ι: hgt P > 0, N P ≥ 0, (1.2) as used, (1.3), and Claim 6 with α ℓ → 0 and |β ℓ| ≤ B for ℓ ≥ L₀. Conclusion: for every ε > 0 there is a constant C with hgt P ≤ (1 + ε) N P + C for all P. No finiteness hypothesis (Remark 5) is used.

Lean statement
theorem vojta_of_claim6 {ι : Type*} (hgt Q N : ι → ℝ) (ℓ : ι → ℕ) (α β : ℕ → ℝ)
  {c c₁ c₂ : ℝ} (hpos : ∀ P, 0 < hgt P) (hN : ∀ P, 0 ≤ N P)
  (h12 : ∀ P, hgt P ≤ Q P + c * (√(hgt P) + 1))
  (h13lo : ∀ P, √(hgt P) ≤ ℓ P)
  (h13hi : ∀ P, (ℓ P : ℝ) ≤ √(hgt P) * (c₁ + c₂ * Real.log (hgt P)))
  (hC6 : ∀ P, Q P ≤ (1 + α (ℓ P)) * N P + β (ℓ P) * ℓ P)
  (hα : Tendsto α atTop (𝓝 0)) (hβ : ∃ B L₀, ∀ n ≥ L₀, |β n| ≤ B) :
  ∀ ε > 0, ∃ C : ℝ, ∀ P, hgt P ≤ (1 + ε) * N P + C

IUT.Audit.ScholzeStix.Section1_3

Scholze–Stix, Section 1.3: the arithmetic of displays (1.4), (1.5), (1.6)

IUT.Audit.ScholzeStix.display_1_5

Display (1.5): with l = 2·ℓ^> + 1, the average with squares equals (ℓ^> + 1)/2 · (d − qE/6).

Lean statement
theorem display_1_5 {lh : ℕ} (hlh : 1 ≤ lh) {l : ℝ} (hl : l = 2 * lh + 1) (d qE : ℝ) :
  thetaWithSquares lh l d qE = ((lh : ℝ) + 1) / 2 * (d - qE / 6)

IUT.Audit.ScholzeStix.display_1_6

Display (1.6): the average without squares equals (ℓ^> + 1)/2 · d − qE/(2ℓ).

Lean statement
theorem display_1_6 {lh : ℕ} (hlh : 1 ≤ lh) (l d qE : ℝ) :
  thetaWithoutSquares lh l d qE = ((lh : ℝ) + 1) / 2 * d - qE / (2 * l)

IUT.Audit.ScholzeStix.consequence_with_squares

Substituting (1.5) into (1.4): (1/6)·qE·(1 − 12/(ℓ(ℓ+1))) ≤ d. Scholze and Stix write this as (1/6) deg(q_E) ≲ (1 − 12/(ℓ(ℓ+1)))⁻¹ · d(P).

Lean statement
