Obstacles

The countermodel catalog: checked examples showing that a general principle, which an argument might be tempted to use, is false without further hypotheses, together with the positive results and lemmas recorded beside them; and the obligations that remain open.

blocked by missing justification (BLOCKED_BY_MISSING_JUSTIFICATION): the text gives an assertion where a formalization needs a derivation; this is not a claim that the result is false.

What a countermodel refutes. A counterexample to a simplified abstraction does not refute a statement of the papers. Each entry names the principle it refutes and whether the hypotheses it satisfies are those of an actual claim. The project keeps seven categories apart: failure of proof search, missing library theorem, gap in the formalization, insufficient hypotheses, counterexample to a simplified abstraction, counterexample to a faithfully formalized statement, and demonstrated contradiction. The countermodels of the catalog are in the fifth category.

IUT.Countermodels.mul_iso_not_additive

On the field ZMod 5, cubing is a bijection that preserves 0, 1 and multiplication but not addition. So an isomorphism of multiplicative monoids need not be a ring isomorphism: data that keeps only the multiplicative structure of a ring does not determine its additive structure. Bears on: IUT III distinguishes links that preserve multiplicative data only (the Θ-link) from ring isomorphisms. The example shows the distinction is not vacuous already for finite fields. It says nothing about whether additive structure can be reconstructed from richer data such as a Galois action.

Lean statement
theorem mul_iso_not_additive :
  ∃ f : ZMod 5 → ZMod 5, Function.Bijective f ∧ f 0 = 0 ∧ f 1 = 1 ∧
    (∀ x y, f (x * y) = f x * f y) ∧ ¬ ∀ x y, f (x + y) = f x + f y

IUT.Countermodels.separate_witnesses_no_joint

Two existence statements, each true, with no common witness. Existence of an object compatible with condition P and existence of an object compatible with condition Q do not give one object compatible with both. Bears on: the simultaneous validity of several compatibility conditions in IUT III, Theorem 3.11, must be proved as a joint statement. It cannot be inferred from the separate ones.

Lean statement
theorem separate_witnesses_no_joint :
  ∃ P Q : Bool → Prop, (∃ x, P x) ∧ (∃ x, Q x) ∧ ¬ ∃ x, P x ∧ Q x

IUT.Countermodels.invariant_comp

The positive statement: a quantity invariant under each of two transformations is invariant under their composite. Invariance under (Ind1) and under (Ind2) separately does give invariance under the combined action, for a single-valued quantity.

Lean statement

  (hg : ∀ x, F (g x) = F x) (hh : ∀ x, F (h x) = F x) : ∀ x, F (g (h x)) = F x

IUT.Countermodels.separate_orbits_ne_joint_orbit

The countermodel: the union of the orbits of a point under two transformations taken separately can be strictly smaller than its orbit under the group they generate. On Fin 3 with the transpositions (0 1) and (1 2), the point 0 has separate orbits {0, 1} and {0}, while the composite (1 2) ∘ (0 1) sends 0 to 2. Bears on: "the union of the possible images" in IUT III, Corollary 3.12, is taken under (Ind1), (Ind2), (Ind3) acting together. A region that contains the images under each indeterminacy separately need not contain the images under their combination, so a volume bound must be established for the combined action.

Lean statement
theorem separate_orbits_ne_joint_orbit :
  let g : Equiv.Perm (Fin 3) := Equiv.swap 0 1
  let h : Equiv.Perm (Fin 3) := Equiv.swap 1 2
  (h (g 0) ∉ ({0, g 0, h 0} : Finset (Fin 3)))

IUT.Countermodels.hull_transport_not_commute

Hull formation does not commute with transport along a bijection that does not respect the structure defining the hull. With s = {0, 2} and σ = (1 2): the hull of σ(s) = {0, 1} is {0, 1}, while σ of the hull of s is everything. Bears on: in Corollary 3.12 the holomorphic hull is formed relative to one arithmetic holomorphic structure (labeled 1, ∘), after transporting data that originates in another. The order of "transport" and "form the hull" matters, and the proof must say which is used.

Lean statement
theorem hull_transport_not_commute :
  let σ : Equiv.Perm (Fin 3) := Equiv.swap 1 2
  let s : Finset (Fin 3) := {0, 2}
  intervalHull (s.map σ.toEmbedding) ≠ (intervalHull s).map σ.toEmbedding

IUT.Countermodels.additive_iso_changes_volume

Doubling x ↦ 2x is additive on ℝ, and the interval [2 · 0, 2 · 1] has Lebesgue measure different from that of [0, 1]. (Doubling is an automorphism of the topological group ℝ; the theorem states only its additivity, not its bijectivity or continuity.) So an isomorphism of topological groups need not preserve a chosen normalization of Haar measure. Bears on: log-volumes in IUT III and IV are normalized. Transporting a volume along an isomorphism that preserves only a weaker structure requires a separate proof that the normalization is preserved.

Lean statement
theorem additive_iso_changes_volume :
  (∀ x y : ℝ, 2 * (x + y) = 2 * x + 2 * y) ∧
    MeasureTheory.volume (Set.Icc (2 * 0 : ℝ) (2 * 1)) ≠ MeasureTheory.volume (Set.Icc (0 : ℝ) 1)

IUT.Countermodels.log_volume_shift

The arithmetic behind the corresponding statement for log-volumes: for c > 0 and μ > 0, log (c μ) = log c + log μ. So rescaling a measure by c > 0 shifts the log-volume of every set of finite positive measure by log c; for a set of measure 0 or ∞ the log-volume log (μ s).toReal is 0 by totalization and no shift occurs. Two normalizations give comparable log-volumes only after the shift is accounted for.

Lean statement
theorem log_volume_shift {c μ : ℝ} (hc : 0 < c) (hμ : 0 < μ) :
  Real.log (c * μ) = Real.log c + Real.log μ

IUT.Countermodels.MulAdd.padic_inv_countermodel

Local field countermodel. On ℚ_p, inversion (with 0⁻¹ = 0) is a bijection that preserves 0, 1 and multiplication, commutes with every field automorphism, is continuous on ℚ_p^×, and maps the unit group {‖x‖ = 1} onto itself. It is nevertheless induced by no ring endomorphism, and it does not preserve the absolute value: it sends p, of norm p⁻¹, to an element of norm p. So the multiplicative monoid of ℚ_p with its topology, its unit group and the action of its field automorphisms does not determine the additive structure, and an isomorphism that is the identity on units can still reverse the value group. Bears on: the description of the Θ×μ_LGP-link as a unit portion together with a value group portion (IUT III, page 175, Step (i) of the proof of Corollary 3.12) and the fact that log-shells are built from units only (IUT III, Remark 1.1.1 (i), page 28). The example says nothing about reconstructions from richer data, such as the absolute Galois group of ℚ_p used in the papers.

Lean statement
theorem padic_inv_countermodel (p : ℕ) [Fact p.Prime] :
  let f : ℚ_[p] → ℚ_[p] := fun x => x⁻¹
  Function.Bijective f ∧ f 0 = 0 ∧ f 1 = 1 ∧ (∀ x y, f (x * y) = f x * f y) ∧
    (∀ σ : ℚ_[p] ≃+* ℚ_[p], ∀ x, f (σ x) = σ (f x)) ∧ ContinuousOn f {0}ᶜ ∧
    (∀ x : ℚ_[p], ‖x‖ = 1 → ‖f x‖ = 1) ∧ ‖f p‖ ≠ ‖(p : ℚ_[p])‖ ∧
    ¬ ∃ σ : ℚ_[p] →+* ℚ_[p], ∀ x, x ≠ 0 → σ x = f x

Countermodel on a unit group. IUT.Countermodels.MulAdd.squareValue_countermodel

Countermodel shaped like a unit portion plus a value group portion. The map squareValue p preserves 0, 1 and multiplication, is injective, and is the identity on every element of norm 1 (the units of ℤ_p). It doubles the valuation of every nonzero element. It is not additive. So a multiplicative map that is the identity on the unit portion and acts on the value group portion by a homomorphism of value groups (here multiplication by 2) need not be compatible with addition. This is a model of the abstraction "identify the units, rescale the value group"; it is not a model of the Θ×μ_LGP-link, which is a poly-isomorphism of Frobenioid theoretic prime-strips rather than a map on a field (IUT III, page 175).

    (∀ x y, squareValue p (x * y) = squareValue p x * squareValue p y) ∧
    Function.Injective (squareValue p) ∧
    (∀ x : ℚ_[p], x ≠ 0 → ‖x‖ = 1 → squareValue p x = x) ∧

IUT.Countermodels.MulAdd.additive_of_mul_of_translate

Positive statement. On any field, a map that preserves multiplication, sends 0 to 0, and commutes with the translation x ↦ x + 1 is additive (hence a ring endomorphism, since f 1 = f 0 + 1 = 1).
