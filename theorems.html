The abc conjecture, as the project states it

For every positive real ε there is a constant K such that every sum a + b = c of coprime positive integers satisfies c ≤ K · rad(abc)1 + ε. This definition is the target. It is never assumed anywhere in the library.

def ABC : Prop :=
  ∀ ε : ℝ, 0 < ε → ∃ K : ℝ, 0 < K ∧ ∀ a b c : ℕ, 0 < a → 0 < b → 0 < c →
    Nat.Coprime a b → a + b = c → (c : ℝ) ≤ K * (rad (a * b * c) : ℝ) ^ (1 + ε)

Challenge.ABC in Challenge.Defs

The logarithmic form is equivalent

The height form log c ≤ (1 + ε) log rad(abc) + C, which is the shape of the inequality in IUT IV, is equivalent to the constant form. The proof is unconditional.

theorem abc_iff_abcLog : ABC ↔ ABCLog

IUT.ABC.abc_iff_abcLog in IUT.Applications.ABC

The finiteness form is equivalent

The statement that only finitely many coprime triples have c > rad(abc)1 + ε for each ε is equivalent to the constant form. This is the primary form in the Formal Conjectures project.

theorem abc_iff_abcFinite : ABC ↔ ABCFinite

IUT.ABC.abc_iff_abcFinite in IUT.Applications.ABC

The hypotheses are not empty

The triple 1 + 1 = 2 satisfies every hypothesis of the formulations, so none of them is true for the empty reason that nothing satisfies its hypotheses.

theorem hypotheses_nonvacuous :
  ∃ a b c : ℕ, 0 < a ∧ 0 < b ∧ 0 < c ∧ Nat.Coprime a b ∧ a + b = c

Corollary 3.12: the reformulation does not give finiteness

The statement of Corollary 3.12 rephrases its inequality as a bound CΘ ≥ −1. This theorem shows that the rephrased form also holds when −|log(Θ)| is +∞. So the claim that −|log(Θ)| is a real number is a separate assertion of the corollary, not a consequence of the rephrased form.

variable (v : PilotLogVolumes)
theorem constantForm_of_top (h : v.negLogTheta = ⊤) : ConstantForm v

Corollary 3.12: the last step is formal

The proof ends by saying that the inequality follows formally from an inclusion of sets. At the level of the two numbers the inclusion and the inequality are the same proposition. All mathematical content of the final step lies in establishing the inclusion, which needs the multiradial representation itself.

variable (v : PilotLogVolumes)
theorem stepXIf_inclusion_iff_inequality :
  -v.absLogQ ∈ possibleLogVolumes v ↔ ((-v.absLogQ : ℝ) : EReal) ≤ v.negLogTheta

From Corollary 3.12 to the inequality of IUT IV, Theorem 1.10

A conditional theorem: if the two numbers satisfy the conclusion of Corollary 3.12 and the bound displayed in Theorem 1.10, the final inequality of Theorem 1.10 follows by real arithmetic. It does not show that the objects of the papers satisfy either hypothesis.

variable (v : PilotLogVolumes)
theorem thm1_10_final_of_cor312 {l d D E Q : ℝ} (hl : 7 ≤ l) (hd : 1 ≤ d) (hD : 0 ≤ D)
  (hE : 0 ≤ E)
  (hbound : v.negLogTheta ≤ ((constant l d D E Q v.absLogQ * v.absLogQ : ℝ) : EReal))
  (hcor : Conclusion v) :
  1 / 6 * Q ≤ (1 + 20 * d / l) * D + 20 * E

IUT.PaperIII.Corollary312.thm1_10_final_of_cor312 in IUT.PaperIII.Corollary312.Numerical

IUT IV, Theorem 1.10: the final real inequality

The last manipulation in the proof of Theorem 1.10, checked for real numbers under the side conditions that the paper cites (the prime l is at least 7, the degree is at least 1, and two sums are nonnegative).

theorem final_inequality {l d D E Q q : ℝ} (hl : 7 ≤ l) (hd : 1 ≤ d) (hD : 0 ≤ D)
  (hE : 0 ≤ E) (hq : 0 < q) (hC : -1 ≤ constant l d D E Q q) :
  1 / 6 * Q ≤ (1 + 20 * d / l) * D + 20 * E

Scholze and Stix: the inequality without the factor j²

In the simplified picture of Scholze and Stix, removing the factor j² makes the q terms cancel exactly, and the resulting inequality says only that the log root discriminant is nonnegative. This checks their arithmetic; whether the simplified picture describes IUT III is the disputed point.

theorem consequence_without_squares {lh : ℕ} (hlh : 1 ≤ lh) (l d qE : ℝ) :
  -(qE / (2 * l)) ≤ thetaWithoutSquares lh l d qE ↔ 0 ≤ d

IUT.Audit.ScholzeStix.consequence_without_squares in IUT.Audit.ScholzeStix.Section1_3

Scholze and Stix: a cycle of linear identifications

If every identification between copies of the real numbers is multiplication by a positive scalar, a cycle with the scalar j² on one edge and the identity elsewhere is inconsistent for j ≥ 2. The theorem is conditional on that linearity hypothesis, which Mochizuki rejects.

theorem not_consistent_square {j : ℕ} (hj : 2 ≤ j) (n : ℕ) :
  ¬ Consistent (⟨(j : ℝ) ^ 2, by positivity⟩ :: List.replicate n LinIdent.canonical)

Mochizuki's example: a non-linear relation

For the two regions of Mochizuki's example, the log-volumes log(4a + 2b) and log(4a + 4b) are not related by a fixed linear map. The example shows that the linearity hypothesis can fail for a hull under a group of indeterminacies; it does not show that IUT III behaves like the example.

theorem not_linear : ¬ ∃ c : ℝ, ∀ a b : ℝ, 0 < a → 0 < b → logVolS a b = c * logVolR a b

IUT.Audit.MochizukiResponses.not_linear in IUT.Audit.MochizukiResponses.LVEx

Multiplicative data does not determine addition

On the field with five elements, cubing preserves 0, 1 and multiplication but not addition. An isomorphism of multiplicative monoids need not be a ring isomorphism. This refutes a simplified principle, not a statement of the papers.

theorem mul_iso_not_additive :
  ∃ f : ZMod 5 → ZMod 5, Function.Bijective f ∧ f 0 = 0 ∧ f 1 = 1 ∧
    (∀ x y, f (x * y) = f x * f y) ∧ ¬ ∀ x y, f (x + y) = f x + f y

IUT.Countermodels.mul_iso_not_additive in IUT.Countermodels.Basic

Indeterminacies act jointly

The orbit of a point under two transformations taken separately can be smaller than its orbit under the group they generate. A bound that covers each indeterminacy separately need not cover their combined action.

theorem separate_orbits_ne_joint_orbit :
  let g : Equiv.Perm (Fin 3) := Equiv.swap 0 1
  let h : Equiv.Perm (Fin 3) := Equiv.swap 1 2
  (h (g 0) ∉ ({0, g 0, h 0} : Finset (Fin 3)))
