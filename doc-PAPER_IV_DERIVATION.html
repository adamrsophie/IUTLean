IUT IV: the derivation from IUT III Corollary 3.12 to the abc inequality

This document follows the chain of results in Inter-universal Teichmüller Theory IV (April 2020 manuscript) that leads from IUT III, Corollary 3.12 to Theorem A and from there to the abc inequality. For each step it records what is used, which external results are cited, which Lean declarations check it, and which obligations remain open. Page numbers are PDF pages of IUT IV.

Pages read: the whole paper (pages 1 to 87) from the extracted text; Sections 1 and 2 line by line; rendered pages 3, 9 to 17, 21 to 31, 40 to 48, 54 to 56, 67, 68, and IUT III page 174.

Nothing in this chain is formalized end to end. The Lean files check the real arithmetic of each step relative to hypotheses that encode the arithmetic geometry; those hypotheses are named in each theorem.

In data/curated/iut4.json every Lean lemma that checks one step is its own fragment record (<parent>.frag.<name>); the records for the statements and proof steps themselves carry no Lean declaration and the status EXTRACTED, except Propositions 1.6, 1.7 and 2.1, whose Lean theorems (proposition1_6, weighted_averages, proposition2_1) state the whole proposition.

Dependency grades used in data/curated/iut4.json (field cor3_12_dependency):

  • independent: does not use IUT III Theorem 3.11 or Corollary 3.12 (Propositions 1.1 to 1.8, Definition 1.9, Steps (i) to (iii) of the proof of Theorem 1.10, Proposition 2.1, Corollary 2.2 (i) and (C1), proof steps (P1) to (P7) of Corollary 2.2).
  • setup_only: uses the multiradial representation of IUT III Theorem 3.11 and the notion of an admissible bound C_Θ from the statement of Corollary 3.12, but not the inequality C_Θ ≥ −1 (Steps (iv) to (viii) of Theorem 1.10, which show that the displayed value is admissible). Corollary 3.12 quantifies over all admissible real C_Θ (IUT III page 174); Theorem 1.10 supplies one. Theorem 3.11 does not construct C_Θ.
  • conditional: uses C_Θ ≥ −1 (the final inequality of Theorem 1.10, Corollary 2.2 as a whole, its (C2) and (iii), the application of Theorem 1.10 and the assembly in its proof, Corollary 2.3, Theorem A). Corollary 2.2 (iii) is graded conditional because it controls the exceptional sets of (ii); its arithmetic step alone is independent.

Step 1: IUT III Corollary 3.12 → Theorem 1.10

Statement (pages 22 to 23). Hypotheses: a collection of initial Θ-data in the situation of IUT III Corollary 3.12; E_F has good reduction at every valuation in 𝕍(F)^good ∩ 𝕍(F)^non not dividing 2l; d_mod = [F_mod : ℚ], e_mod the maximal ramification index of F_mod over ℚ, d*_mod = 2¹²·3³·5·d_mod, e*_mod = 2¹²·3³·5·e_mod; the tripodal field F_tpd = F_mod(E_{F_mod}[2]); the 3·5-torsion of E_F is defined over F; F = F_tpd(√−1, E_{F_tpd}[3·5]). Then the real number

(l+1)/(4·|log(q)|)·{(1 + 12·d_mod/l)·(log(𝔡^{F_tpd}) + log(𝔣^{F_tpd})) + 10·(e*_mod·l + η_prm) − (1/6)·(1 − 12/l²)·log(𝔮)} − 1,

is an admissible C_Θ for IUT III Corollary 3.12. Here |log(q)| = log(𝔮)/(2l) (page 23). In Lean, Theorem1_10.constant l d D E Q q keeps q (for |log(q)|) and Q (for log(𝔮)) as separate variables; the relation q = Q/(2l) is a hypothesis of constant_bound_of_raw and step_viii_constant. Then, by C_Θ ≥ −1, (1/6)·log(𝔮) ≤ (1 + 20·d_mod/l)·(log(𝔡^{F_tpd}) + log(𝔣^{F_tpd})) + 20·(e*_mod·l + η_prm). The statement does not list a bound on l: l is a prime ≥ 5 by IUT I Definition 3.1, and page 22 notes l ≠ 5 (the 5-torsion is rational over F), so l ≥ 7, which the final estimate uses.

Uses. Propositions 1.3, 1.4, 1.5, 1.6, 1.7, 1.8; Definition 1.9; IUT III Theorem 3.11 and Corollary 3.12; IUT I Definition 3.1.

External. [IUTchIII] Theorem 3.11, Corollary 3.12, Proposition 3.9; [AbsTopIII] Propositions 5.7, 5.8 (log-volumes); [DmMn] §3.10 (prime number theorem, through Proposition 1.6); [Silv], [NerMod] (through Proposition 1.8).

Step 2: Theorem 1.10 → Corollary 2.2

Statement (pages 41 to 43). For X = ℙ¹, D = {0, 1, ∞} (the λ-line) and a compactly bounded K_V ⊆ U_X(ℚ̄) containing the prime 2 in its support and satisfying (*_{j-inv}): (i) (1/6)·log(𝔮^{∤2}) ≈ (1/6)·log(𝔮^∀) ≈ (1/6)·ht_∞ ≈ ht_{ω_X(D)} on K_V; (ii) outside a finite set Exc_{ε_d}, an elliptic curve with a point x_E ∈ K_V arises from initial Θ-data with (C1) h^{1/2} ≤ l ≤ 10δ·h^{1/2}·log(2δh) and (C2) (1/6)·log(𝔮^∀) ≤ (1 + ε_E)·(log-diff_X(x_E) + log-cond_D(x_E)) + C_K, where δ = 2¹²·3³·5·d, h = log(𝔮^∀), ε_E = (60δ)²·h^{−1/2}·log(2δh), and log(𝔮^∀) ≤ H_unif·ε_d^{−3}·d^{4+ε_d} + H_K on Exc_{ε_d} (page 42); (iii) the exceptional sets can be chosen with log(𝔮^∀) ≤ H_unif·ε^{−3}·ε_d^{−3}·d^{4+ε_d} + H_K and ε_E ≤ ε outside them.

Uses. Proposition 2.1; Theorem 1.10 (final inequality) with Remark 1.10.7 (i); Proposition 1.8.

Step 3: Corollary 2.2 → Corollary 2.3 = Theorem A

Statement (page 54). For X smooth, proper, geometrically connected over a number field, D reduced with U_X hyperbolic, d ≥ 1, ε > 0: ht_{ω_X(D)} ≲ (1 + ε)·(log-diff_X + log-cond_D) on U_X(ℚ̄)^{≤d}.

Proof (pages 54 and 55). The statement is [GenEll] Theorem 2.1 (i). By the equivalence of [GenEll] Theorem 2.1 it suffices to prove [GenEll] Theorem 2.1 (ii), i.e. the inequality on K_V ∩ U_X(ℚ̄)^{≤d} for the λ-line, which follows from Corollary 2.2 (i), (ii) (C2), (iii) using d_mod ≤ d.

External. [GenEll] Theorem 2.1 (Belyi maps, noncritical Belyi maps), with the corrections of Remark 2.3.1 (ii) and (v).

Step 4: Theorem A → abc

The paper does not write out this specialization. The standard one is:

  • Curve and divisor. X = ℙ¹_ℚ, D = {0, 1, ∞}, U_X = ℙ¹ \ {0, 1, ∞}. Then deg ω_X(D) = −2 + 3 = 1 > 0, so U_X is hyperbolic.
  • Degree bound. d = 1: points over ℚ.
  • Point. For positive integers a + b = c with gcd(a, b) = 1, take x = a/c = [a : c]. Since a, b > 0, x ≠ 0, 1, ∞, so x ∈ U_X(ℚ).
  • Height. ω_X(D) ≅ 𝒪(1), and ht_{𝒪(1)}([a : c]) = log max(|a|, |c|) = log c for coprime a, c with the standard metric; heights are defined only up to bounded discrepancy, so ht_{ω_X(D)}(x) ≈ log c.
  • Log-different. The minimal field of definition is ℚ, whose different is trivial, so log-diff_X(x) = deg_ℚ(δ_x) = 0 ([GenEll] Definition 1.5 (iii)).
  • Log-conductor. The morphism Spec ℤ → ℙ¹_ℤ given by [a : c] meets 0 at the primes dividing a, 1 at the primes dividing c − a = b, and ∞ at the primes dividing c. The reduced pullback (D_x)_red is ∑_{p | abc} p, so log-cond_D(x) = ∑_{p | abc} log p = log rad(abc) ([GenEll] Definition 1.5 (iv)). Over ℚ normalized and unnormalized degrees agree.
  • Conclusion. Theorem A gives, for each ε > 0, a constant C_ε with log c ≤ (1 + ε)·log rad(abc) + C_ε for all such triples.

**Relation to Challenge.ABCLog.** Challenge/Defs.lean defines Challenge.ABCLog as: for every ε > 0 there is C such that for all positive a, b, c with Nat.Coprime a b and a + b = c, Real.log c ≤ (1 + ε)·Real.log (rad (a*b*c)) + C. This is exactly the conclusion above, and IUT/Applications/ABC.lean proves ABC ↔ ABCLog (abc_iff_abcLog).

**The reduction Theorem A → Challenge.ABCLog is not formalized.** Mathlib has no heights, log-differents or log-conductors on curves over number fields, and Theorem A itself is not formalized. The specialization above is a paper-level argument.
