Source manifest

Generated by scripts/gen_docs.py from data/source_manifest.json, which scripts/extract_statements.py computes from the PDFs. Do not edit by hand.

The PDFs in hand are the author's manuscript versions, dated on their title pages as below. They are not the journal typesetting: page numbers in this project are manuscript page numbers (in these files the PDF page number equals the printed page number), and they differ from the journal pagination listed under Publication. The publication data was checked by resolving each DOI at doi.org and reading its Crossref record; the check date is recorded with each entry.

Where to get the PDFs

The PDFs are not redistributed in this repository. They are the author's manuscripts, listed on the author's page of papers, https://www.kurims.kyoto-u.ac.jp/~motizuki/papers-english.html, under the file names given below; the journal editions linked by the DOIs are paginated differently and are not the files indexed here. Put the four files in one folder and run python3 scripts/extract_statements.py index <folder>: it first compares the SHA-256 of each file with the value below and stops on a difference. The author updates the manuscripts from time to time, so a file downloaded later may be a different edition; the hash check then fails rather than index it.
