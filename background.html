Every statement of the project cites these files by page; the PDF page number equals the printed page number. IUT III, Corollary 3.12

Corollary 3.12 (IUT III, pages 173 to 186) defines two numbers from a collection of initial Θ-data. The first, written −|log(Θ)|, is the normalized log-volume of the holomorphic hull of the union of the possible images of a Θ-pilot object under the three indeterminacies (Ind1), (Ind2), (Ind3); it lies in ℝ ∪ {+∞}. The second, −|log(q)|, is the corresponding log-volume of a q-pilot object, which is not subject to the indeterminacies; |log(q)| is positive. The corollary asserts that −|log(Θ)| is a real number and that −|log(Θ)| ≥ −|log(q)|.

The project does not yet construct either number: Hodge theaters, the log-theta-lattice and the multiradial representation are not formalized. The Lean module IUT.PaperIII.Corollary312.Numerical formalizes only the shape of the conclusion once the two numbers are given:

variable (v : PilotLogVolumes)
def Conclusion : Prop :=
  v.negLogTheta ≠ ⊤ ∧ ((-v.absLogQ : ℝ) : EReal) ≤ v.negLogTheta

IUT IV, Theorem 1.10

Theorem 1.10 (IUT IV, pages 22 to 31) turns the inequality of Corollary 3.12 into an explicit estimate. Its first assertion is a bound −|log(Θ)| ≤ CΘ · |log(q)| for an explicit constant CΘ; combined with Corollary 3.12 it gives an inequality of the form (1/6) log(𝔮) ≤ (1 + 20 dmod/l) (log 𝔡 + log 𝔣) + 20 (e*mod l + ηprm), in the notation of the paper. In the citation index, IUT IV, Corollary 2.2 cites Theorem 1.10, and Corollary 2.3, titled Diophantine Inequalities, cites Corollary 2.2.

The module IUT.PaperIV.Theorem1_10.Arithmetic checks the real arithmetic of the proof with every quantity of the paper as a real variable. It does not construct the arithmetic objects, and it does not show that they satisfy the hypotheses.

The target is stated once, in the trusted file Challenge/Defs.lean, in three formulations. The module IUT.Applications.ABC proves, unconditionally, that the three are equivalent. Nothing in the library proves any of them.

Constant form

The abc conjecture, constant form. For every real ε > 0 there is a real constant K > 0, depending on ε only, such that every triple of positive integers a, b, c with a and b coprime and a + b = c satisfies c ≤ K * rad (a * b * c) ^ (1 + ε). Because a + b = c, coprimality of a and b is the same as pairwise coprimality of the three numbers; see Solution.coprime_iff_pairwise. The exponent is a real power.

def ABC : Prop :=
  ∀ ε : ℝ, 0 < ε → ∃ K : ℝ, 0 < K ∧ ∀ a b c : ℕ, 0 < a → 0 < b → 0 < c →
    Nat.Coprime a b → a + b = c → (c : ℝ) ≤ K * (rad (a * b * c) : ℝ) ^ (1 + ε)

Finiteness form

The abc conjecture, finiteness form: for every ε > 0 only finitely many coprime triples a + b = c have c > rad (a * b * c) ^ (1 + ε). This is the primary form in the Formal Conjectures project (FormalConjectures/Wikipedia/ABC.lean, theorem ABC.abc), with the pairwise coprimality written there replaced by the equivalent coprimality of a and b.

def ABCFinite : Prop :=
  ∀ ε : ℝ, 0 < ε → {t : ℕ × ℕ × ℕ | 0 < t.1 ∧ 0 < t.2.1 ∧ 0 < t.2.2 ∧
    Nat.Coprime t.1 t.2.1 ∧ t.1 + t.2.1 = t.2.2 ∧
    ((rad (t.1 * t.2.1 * t.2.2) : ℝ) ^ (1 + ε) < t.2.2)}.Finite

Logarithmic form

The abc conjecture, logarithmic form: log c ≤ (1 + ε) * log (rad (a b c)) + C. This is the shape in which the statement appears as a height inequality (compare the inequality ht ≲ (1 + ε)(log-diff + log-cond) of IUT IV, Theorem A, for the projective line minus three points and rational points).

def ABCLog : Prop :=
  ∀ ε : ℝ, 0 < ε → ∃ C : ℝ, ∀ a b c : ℕ, 0 < a → 0 < b → 0 < c →
    Nat.Coprime a b → a + b = c →
      Real.log c ≤ (1 + ε) * Real.log (rad (a * b * c)) + C

Indices, places and labels
  • V, V^bad, V^good, V^non, V^arc: places of K from the initial Θ-data (IUTchI Def 3.1). Used throughout, e.g. page 24 (r).
  • V_Q, v_Q: places of Q; v | v_Q means v lies over v_Q. Page 89 (r), Rem 2.4.2 (ii).

  • l*: the largest label in F*_l; the theta values are q^{j²}, j = 1, ..., l* (Fig. 3.4, page 173 (r)). Defined in IUTchI; its formula was not read here.
  • S^±_{j+1}: the index set of the capsule of the procession used at label j; its log-shells carry the labels {0, 1, ..., j} (Rem 3.9.3, page 120 (r)). Prop 3.4 (ii), pages 101 to 103 (t); used in Thm 3.11 (i)(a), page 153 (r).
  • (n,m) ∈ Z × Z: lattice position. Def 1.4, page 45 (r).
  • n,◦: vertically coric object of the n-th column. Thm 1.5 (i), page 48 (r); Thm 3.11, page 153 (r).
  • △: the result of identifying the labels 0 and ⟨F*_l⟩. Recalled in Cor 3.12, page 174 (r), citing IUTchII Cor 4.10 (i).
  • ≻, >: labels of D-prime-strips in a Θ^{±ell}NF-Hodge theater. Thm 1.5 (iii), pages 48 to 49 (r), citing IUTchI.

  • p*_v: p_v if p_v is odd, p_v² if p_v is even. Def 1.1 (i), page 24 (r).
  • I_{†F_v}: log-shell. At nonarchimedean v it is (p*_v)^{-1} times the pre-log-shell, the image of the G_v-invariants of the units. Def 1.1 (i), page 24 (r). The archimedean version is in Def 1.1 (ii), page 25 (r).

Pilot objects
  • Θ-pilot object: the object of ∏_{j∈F*_l} (F_MOD)_j or ∏_j (F_mod)_j, or its realification, determined by generators up to torsion of Ψ^⊥_{F_lgp}(HT)_v, v ∈ V^bad. Def 3.8 (i), page 112 (r).
  • q-pilot object: the object of C^⊩_△ determined by generators up to torsion of the splitting monoid of F^⊢_{△,v}, i.e. by the q_v. Def 3.8 (i), page 112 (r).
Log-volumes
  • M(−): the set of nonempty compact open subsets (nonarchimedean), or of compact closures of nonempty open subsets (archimedean). Prop 3.9 (i), pages 115 to 116 (r).
  • μ^log_{α,v_Q}, μ^log_{A,v_Q}, μ^log_{A,α,v}: packet-normalized log-volumes M(I^Q(−)) → R. Prop 3.9 (i), page 115 (r).
    • Integral structures have log-volume 0.
    • At nonarchimedean places, multiplication by p_v adds −log(p_v).
    • At archimedean places, multiplication by e adds 1.
  • Procession-normalization: the average over the capsules of a procession. Prop 3.9 (i), page 116 (r). Cor 3.12 states that the average is over j ∈ F*_l (pages 173 and 181 (r)), so the factor is 1/l*; the capsules of Prop 3.4 (ii) carry the labels j ∈ {1, ..., l*} = F*_l (page 102 (r)). Page 183 (r) speaks of a normalization "with respect to j ∈ |F_l|" without a factor.
  • μ^log_{A,V_Q}: global log-volume, the sum over v_Q. Prop 3.9 (iii), page 117 (r).
  • Sub(M), Fn(M), Rss(M): pre-ample subsets, finite-valued Borel functions, and the quotient by integration. Rem 3.9.4 (i), page 120 (r).
  • log(q) = ord_v(q_v)·log(p_v). Rem 3.9.4 (iv), page 124 (r).
  • −|log(Θ)| ∈ R ∪ {+∞}: procession-normalized mono-analytic log-volume of the holomorphic hull of the union of possible images of a Θ-pilot object, subject to (Ind1), (Ind2), (Ind3). Cor 3.12, pages 173 to 174 (r).
  • −|log(q)| ∈ R: the log-volume of the image of a q-pilot object, not subject to the indeterminacies. Cor 3.12, page 174 (r).
  • C_Θ: any real number with −|log(Θ)| ≤ C_Θ·|log(q)|. Cor 3.12, page 174 (r).
  • R_{≤−|log(Θ)|} = {λ ∈ R | λ ≤ −|log(Θ)|}. Cor 3.12 Step (xi-d), page 183 (r).
Hulls
  • Holomorphic hull: the smallest λ·O containing U, with every component of λ nonzero, for relatively compact U; otherwise the whole I^Q(−). Rem 3.9.5 (i), page 127 (r).
  • ℙ, ℍ, φ: direct product regions, hulls (proper subsets), and the hull map ℙ → ℍ with (P1) to (P3). Rem 3.9.5 (ii), page 127 (r).

  • n,◦U, n,◦U^Q, n,◦Ū: unions of possible images, their ambient packets, and their hulls, indexed by j ∈ |F_l|, v_Q ∈ V_Q (an indexing of sets, not the averaging index). Cor 3.12 proof, page 174 (r).
Indeterminacies and properties
  • (Ind1): induced by automorphisms of the procession. Thm 3.11 (i), page 154 (r).
  • (Ind2): independent copies of Ism (nonarchimedean) or of order 2 automorphisms (archimedean) on each direct summand. Thm 3.11 (i), page 154 (r).

  • Kummer-detachment and étale-transport indeterminacies: Rem 1.5.4 (i), page 56 (t).

Section 3: species and mutations (pages 67 to 87)
Universe and set-theory conventions (pages 67 to 68)
  • ZFC-model. A model of the ZFC axioms ("sets" and ∈).
  • **Grothendieck universe V.** A set with: (i) transitive; (ii) ℕ ∈ V; (iii) closed under power set; (iv) closed under union of members; (v) closed under surjective images of members. A V-set is an element of V.
  • **Existence axiom (†^G). Every set lies in some universe. A ZFC-model satisfying it is a ZFCG-model**. Consequences: any set-indexed family of universes lies in a larger universe; infinite ascending chains V_0 ∈ V_1 ∈ … exist; infinite descending chains do not (foundation).
  • Absoluteness proviso. Every set-theoretic formula used is absolute: its truth for sets in V relative to V is equivalent to its truth relative to any universe W with V ∈ W.
  • The paper does not settle whether ZFCG-models exist; it points to Feferman ([Ffmn]).
