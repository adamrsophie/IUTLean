# Notation of IUT I

Source: Mochizuki, *Inter-universal Teichmüller Theory I*. Each entry gives the page where the
notation is introduced. Pages marked (image) were checked against a rendered page; the others
were read in the extracted text only.

## Conventions for decorations

The paper distinguishes objects by decorations that the extracted text loses. This dictionary
writes them as follows, matching the rendered pages.

| Written here | In the paper | Meaning |
|---|---|---|
| `D_v` with `v` underlined | underline under `v` | element of the chosen set `V ⊆ 𝕍(K)` |
| `X_v` with double underline | double underline | a tempered covering at bad `v` (Example 3.2) |
| `X→` | right arrow over `X` | curve determined by the cusp `ε` (Definition 3.1 (f)) |
| `†`, `‡`, `∗` prefix | left superscript | label of a copy (Remark 3.6.1) |
| `^⊢` | superscript turnstile | mono-analytic (split) version |
| `^⊩` | superscript double turnstile | realified global version |
| `^⊛`, `^⊚` | superscript circled symbols | global objects; `D^⊚ = B(C_K)^0` (Definition 4.1), `D^⊛` (Example 5.1) |
| `_>`, `_≻` | subscript | target prime strip of a Θ- (resp. Θ^±-) bridge |
| `^{⋊±}` | superscript | semidirect product with `{±1}`; dropped in the text, restored from images |
| `F_l^*`, `l^*` | superscript asterisk-like star | written `*` here; the extracted text drops it |
